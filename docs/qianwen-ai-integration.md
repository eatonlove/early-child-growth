# 同迹 3.0 千问 AI 接入说明

## 接入场景

| 场景 | 模型输入 | 固定输出 | 人工控制 |
|---|---|---|---|
| 观察表提取 | DOCX/DOC/PDF文本或可选图片、当前班级幼儿候选 | 标准观察字段、字段置信度、警告 | 教师逐项校对后保存 |
| 游戏观察分析 | 当前幼儿的观察、情境特征、教师识别与应答、历史证据、年龄段知识卡、可选授权媒体 | 事实、七类游戏经验、五大领域、六类学习品质、历史变化、3套应答、复察切口 | 教师分板块审核或反馈生成AI V2 |
| 周期报告 | 周期内已终审观察、分析、支持效果；班级版另含后端统计 | 个体教师版、家长版或班级证据画像 | 教师审核、发布或撤回 |
| 课程活动方向 | 达到门槛的连续证据和年龄段知识 | 固定4个可比较方向 | 教师选择1至3个 |
| 深度课程计划 | 教师已选方向、证据、园所模板版本 | 主题缘起、经验、四区七步框架、环境材料和调整依据 | 教师继续记录第N轮实施 |
| AI修订 | 原分析、教师分板块反馈、同一证据和知识白名单 | 新的结构化分析版本 | 原版本与反馈完整保留 |

知识检索、课程和报告证据门槛、权限校验、教师确认与直接导出权限由业务代码决定，不交给模型自由判断。

## Provider与回退

- `AI_MODE=qianwen`：调用千问 OpenAI 兼容接口。
- `AI_MODE=simulated`：只运行本地规则 Provider。
- `AI_FALLBACK_TO_SIMULATED=true`：千问超时、限流、上游故障、JSON校验或风险守卫失败时，返回明确标记的模拟草稿。
- 每次分析保存 `provider`、`model`、`prompt_version`、知识卡ID、风险提示和是否回退。

## 模型与配置

文本与视觉模型可分别配置：

```dotenv
AI_MODE=qianwen
DASHSCOPE_API_KEY=sk-your-key-here
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_TEXT_MODEL=qwen3.7-plus-2026-05-26
QWEN_VISION_MODEL=qwen3.7-plus-2026-05-26
QWEN_TIMEOUT_MS=120000
QWEN_VISION_TIMEOUT_MS=240000
QWEN_MEDIA_ANALYSIS_ENABLED=false
QWEN_MAX_MEDIA=2
AI_FALLBACK_TO_SIMULATED=true
```

密钥只放在 API 容器环境中，不进入前端、Git、日志或审计详情。

## 多媒体边界

- 只有 `guardian_consent_status=granted` 且显式启用媒体分析时，图片或视频才发送给千问。
- 使用 Supabase 私有对象15分钟签名链接；链接只存在于本次上游请求内。
- 每次发送数量受 `QWEN_MAX_MEDIA` 限制。
- 视频采用视觉模型可读取的画面内容，不把音轨转写能力混同为视觉分析。
- PDF和Word用于文档文本提取，不作为观察视频发送。
- 无授权、签名失败或关闭媒体分析时，仍可使用教师文字和已确认转写。

## 风险守卫

- 千问使用严格 JSON Schema，响应再经 Zod 校验。
- 每条事实只能引用允许的证据ID。
- 每条指标映射只能引用本次检索到的指标编码。
- 五大领域固定返回；无证据领域必须标记不作判断。
- 标签化、医学或心理诊断、幼儿排名、综合评分和确定性达标结论会触发拒绝。
- 单次观察必须保留证据限制与下一次验证重点。
- 多幼儿观察按幼儿分别调用，无法区分归属时不得共享同一结论。

## 验证

- 无真实密钥时使用 mock HTTP 响应验证请求格式、结构化输出、媒体输入、指标白名单和隐私最小化。
- 配置标准密钥后，先关闭媒体分析验证文本链路，再使用虚构且已授权的短视频验证视觉链路。
- 生产发布前应验证真实模型返回仍满足3套应答、5个领域、证据ID和禁止语义守卫。

# AI循证分析服务契约与风险守卫

## 服务定位

AI只生成供教师审核的专业草稿，不生成正式评价，不自动发布报告，不替代教师作出教育决策。

## 输入条件

分析请求必须包含：

- 已保存的观察事件ID。
- 客观白描或经教师确认的媒体转写。
- 幼儿年龄段、游戏场景、主题和组织阶段。
- 本次允许使用的指标版本。
- 可选的既往相关观察证据。

以下情况拒绝分析：

- 观察不存在或当前用户无访问权限。
- 幼儿授权范围不允许处理对应媒体。
- 没有任何可引用的原始证据。
- 请求试图生成诊断、排名、综合分数或入园筛查结论。

## 硬性守卫

- 每条事实必须引用原始证据。
- 每条解释必须标记为可能性语言，并说明证据限制。
- 单次观察自动添加 `single_observation` 风险标记。
- 指标关联只能来自请求允许的已发布指标版本。
- 不得输出“优秀、落后、正常、异常、聪明、能力差”等标签。
- 不得输出医学、心理、特殊教育诊断。
- 不得将没有发生的行为补充为证据。
- 不得使用其他幼儿数据进行横向比较。

## 教师审核

教师必须能够对每条主张执行：

- 采用。
- 修改后采用。
- 拒绝。
- 标记需要更多证据。

审核记录保存原始AI内容、教师修改内容、审核结果、审核人、时间和说明。已审核或已发布内容不得被后续AI任务自动覆盖。

## 质量评估

试点期每周抽样评估：

- 事实证据引用率。
- 无证据主张率。
- 教师采用、修改和拒绝比例。
- 过度推断与标签化发生率。
- 支持策略相关性。
- 支持后复察完成率。

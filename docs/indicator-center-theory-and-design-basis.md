# 指标中心的理论基础与设计依据

> 版本说明（2026-08-21）：童迹3.0已依据教育部教基二〔2012〕4号所附现行公开《3-6岁儿童学习与发展指南》，建立五大领域、11个子领域、32个目标、小中大班共96张年龄参照卡。完整数据结构、判断状态和AI接入规则见 `apps/v3-local/docs/guide-knowledge-base.md`。

## 一、文档目的

本文档用于说明“童迹”幼儿游戏学习与发展循证评估系统中指标中心的理论基础、政策依据、专业转译方法与产品设计原则。

指标中心的核心用途是帮助教师：

- 在真实游戏情境中更有方向地观察幼儿。
- 区分客观事实、专业解释与待验证假设。
- 基于连续证据理解幼儿经验的发展变化。
- 设计适宜的环境、材料和互动支持。
- 将幼儿持续兴趣与问题转化为课程线索。

指标中心不是幼儿考试、筛查、诊断或排名工具，也不是要求所有幼儿在统一时间达到统一表现的达标量表。

---

## 二、核心儿童观与评价观

### 1. 儿童是主动、有能力的学习者

幼儿会主动选择材料、形成游戏意图、提出问题、尝试办法、与同伴协商并表达自己的经验。

因此，指标中心不应只记录幼儿是否完成某项任务，而应关注：

- 幼儿想做什么。
- 幼儿如何理解当前情境。
- 幼儿使用了什么策略。
- 遇到困难后如何调整。
- 幼儿如何借助同伴、教师、材料和环境继续行动。

### 2. 游戏是幼儿学习与发展的基本方式

幼儿的健康、语言、社会、科学和艺术经验不是彼此割裂发展的，而是在建构、角色、沙水、运动、艺术表现等真实游戏中相互交织。

同一次建构游戏可能同时体现：

- 科学领域中的观察、比较和验证。
- 数学经验中的空间关系和测量。
- 语言领域中的表达、解释和记录。
- 社会领域中的协商、合作和规则调整。
- 艺术领域中的想象、表现与创造。
- 游戏品质中的投入、坚持、计划与反思。

因此，一个观察事件可以关联多个指标，但只能关联有直接证据支持的内容。

### 3. 评价服务于儿童后续发展

评价的目的不是证明幼儿“会不会”，而是帮助教师回答：

- 幼儿目前正在形成什么经验？
- 幼儿对什么保持兴趣？
- 幼儿正在解决什么问题？
- 哪些理解仍需继续验证？
- 教师下一步可以提供什么支持？
- 支持以后，幼儿的行动是否发生变化？

系统采用以下循环：

`观察 → 识别 → 应答 → 拓展 → 再观察`

## 三、国家政策与专业依据

### 1. 《3-6岁儿童学习与发展指南》

《指南》从健康、语言、社会、科学、艺术五个领域描述幼儿学习与发展的基本方向，并按照不同年龄阶段提出典型表现与教育建议。

指标中心对《指南》的使用原则：

- 将五大领域作为国家发展目标底座。
- 将年龄段表现用于理解一般发展方向。
- 不将年龄段表现转化为统一达标时间表。
- 不将典型表现直接改造成测验题目。
- 不依据一次行为判断幼儿已经达到或未达到某项目标。

### 2. 《幼儿园教育指导纲要（试行）》

《纲要》强调幼儿园教育应尊重幼儿身心发展规律和学习特点，关注个体差异，促进每个幼儿富有个性的发展。

指标中心据此坚持：

- 各领域内容相互渗透。
- 教育内容来源于幼儿生活和经验。
- 环境、材料、同伴和教师互动都是重要教育资源。
- 教师应成为幼儿学习活动的支持者、合作者和引导者。

### 3. 《幼儿园保育教育质量评估指南》

《评估指南》强调儿童为本、过程导向、持续改进，突出过程评估、自我评估与班级观察，并严禁通过直接测查幼儿能力和发展水平评价幼儿园保教质量。

指标中心据此：

- 聚焦真实班级与游戏过程。
- 关注教师如何支持幼儿学习。
- 关注环境、材料与互动质量。
- 不建设幼儿综合评分、排名或横向比较功能。
- 使用指标帮助园所持续改进，而非形成一次性评价结果。

### 4. 《中华人民共和国学前教育法》

学前教育应遵循学前儿童身心发展规律和年龄特点，坚持保育与教育相结合，以游戏为基本活动。

指标中心据此将儿童权益、发展适宜性和游戏基本活动原则作为不可突破的设计边界。

## 四、核心教育理论

### 1. 建构主义学习理论

幼儿不是被动接收知识，而是在与材料、环境和他人的互动中主动建构理解。

在指标设计中的体现：

- 关注幼儿自己的问题和解释。
- 关注幼儿如何通过操作与结果修正理解。
- 关注策略变化，而不只关注最终结果。
- 允许同一问题存在多种解决路径。

### 2. 社会文化学习理论

幼儿学习发生在社会互动和文化情境之中，语言、符号、材料、同伴和教师都是支持学习的重要工具。

在指标设计中的体现：

- 记录同伴关系和共同活动目标。
- 关注语言如何推动游戏继续。
- 关注幼儿如何借助工具和符号表达经验。
- 分析教师支持介入前后的变化。

### 3. 最近发展区与支架理论

幼儿当前独立完成的行动，与在适宜支持下可以完成的行动之间存在发展空间。

在指标设计中的体现：

- 区分幼儿自主行动与支持后行动。
- 教师支持应适量、可撤回，并逐步归还主动权。
- 不将寻求同伴或教师帮助视为能力不足。
- 通过后续观察判断支持是否真正有效。

### 4. 形成性评价理论

形成性评价强调收集和解释证据，并用证据决定下一步支持。

在指标设计中的体现：

- 指标必须能够指向后续观察和支持策略。
- 教师支持后必须安排复察。
- 评价结论可以随着新证据修正。
- AI生成内容始终是可审核、可修改的草稿。

### 5. 真实性评价

真实性评价强调在真实任务和自然情境中理解儿童的行动。

在指标设计中的体现：

- 证据来自真实游戏、生活、交流和创作。
- 不通过脱离情境的任务直接测试幼儿。
- 优先收集教师白描、幼儿原话、作品序列和关键片段。
- 解释行为时必须保留发生情境。

### 6. 学习故事与教育叙事

学习故事关注儿童的兴趣、投入、关系、策略和可能性，通过叙事看见成长过程。

在指标设计中的体现：

- 关注幼儿正在形成的经验，而非缺陷。
- 记录幼儿行动中的转折点。
- 将幼儿原话和作品作为重要证据。
- 使用成长语言而非标签语言。

### 7. 生态系统理论

幼儿的发展受到家庭、班级、园所、社会文化和制度环境的共同影响。

在指标设计中的体现：

- 不把所有表现简单归因于幼儿个人能力。
- 同时分析时间、空间、材料、关系和成人支持。
- 对长期缺少观察证据的情况，先检查机会是否公平。
- 家园交流聚焦共同支持，不把责任推向家庭。

### 8. 具身学习与多模态表征

幼儿通过身体动作、语言、图画、声音、材料、符号和空间组织共同表达与理解经验。

在指标设计中的体现：

- 不只重视口头表达。
- 将动作、作品、建构和图画纳入证据。
- 允许幼儿使用多种方式回顾和表达游戏经验。
- 艺术表现不以作品是否像范例作为评价依据。

### 9. 课程生成理论

课程可以从幼儿持续出现的兴趣、问题、关系和探究行动中生成。

在指标设计中的体现：

- 识别跨时间持续出现的兴趣和问题。
- 识别多个幼儿共同关注的探究线索。
- 将指标用于发现可拓展经验，而不是规定固定活动。
- 课程实施后继续收集证据并动态调整。

## 五、指标中心的三层结构

### 第一层：国家与理论依据

包含：

- 国家公开文件中的发展方向和教育原则。
- 经审核的教育理论。
- 已取得授权的专业资料。
- 园所经过审核的课程理念。

该层回答：“为什么关注这些内容？”

### 第二层：专业转译

将理论和国家发展方向转化为教师可使用的观察语言，包括：

- 领域与子领域。
- 发展目标。
- 游戏中可观察行为。
- 不能作为证据的常见误判。
- 教师适宜支持策略。
- 适用游戏情境。
- 推荐证据类型。
- 理论转译说明。

该层回答：“教师在游戏中可以看什么、怎样理解、怎样支持？”

### 第三层：个体循证轨迹

将真实观察证据与指标关联，包括：

- 教师客观白描。
- 幼儿原话。
- 照片和视频关键片段。
- 幼儿作品及作品变化。
- 教师支持策略。
- 支持后的后续观察。

该层回答：“当前关于这名幼儿，我们有哪些证据，还需要验证什么？”

## 六、指标的标准结构

每项专业指标至少应包含以下字段：

| 字段 | 作用 |
|---|---|
| 指标编码 | 支持版本、引用和数据分析 |
| 领域与子领域 | 标记指标所属专业结构 |
| 指标名称 | 用成长和行动语言描述关注方向 |
| 理论解释 | 说明指标为何重要以及如何理解 |
| 年龄关注点 | 提示一般发展方向，不作为达标线 |
| 可观察行为 | 帮助教师在真实游戏中识别证据 |
| 不能作为证据 | 防止标签化、过度推断和常见误判 |
| 适宜教师支持 | 将观察结果转化为下一步教育行动 |
| 适用游戏情境 | 帮助推荐观察模板 |
| 推荐证据类型 | 明确形成判断需要收集什么材料 |
| 理论和政策来源 | 保证专业依据可追溯 |
| 转译说明 | 区分国家原文与系统专业转译 |
| 审核与版本信息 | 支持专家治理和持续修订 |

## 七、领域与跨领域指标设计

### 1. 健康领域

主要关注：

- 情绪与身心状态。
- 身体动作协调与控制。
- 手部精细动作。
- 自主照料。
- 风险判断和自我保护。

设计重点：

- 动作发展应服务于真实游戏意图。
- 不以速度、高度、力量进行幼儿排名。
- 风险教育应帮助幼儿学习判断和管理风险，而不是取消全部挑战。

### 2. 语言领域

主要关注：

- 倾听、回应和协商。
- 游戏叙事和经验回顾。
- 图画、符号和文字的真实使用。
- 多模态表达。

设计重点：

- 语言是否推动游戏、合作和问题解决。
- 不以说话次数、成人化表达或识字数量判断语言发展。
- 书写准备来自真实沟通和记录需要。

### 3. 社会领域

主要关注：

- 主动交往和共同游戏。
- 合作、分享与同伴协调。
- 自主选择和责任承担。
- 规则理解、协商和调整。
- 归属感与共同体参与。

设计重点：

- 合作不是简单共同在场。
- 规则意识不等同于被动服从。
- 自主性不等同于完全不寻求帮助。

### 4. 科学领域

主要关注：

- 好奇、提问与持续探究。
- 观察、比较、操作和验证。
- 数量、测量、形状和空间关系。
- 证据意识和问题解决。

设计重点：

- 关注幼儿如何探究，而不是是否得到标准答案。
- 偶然成功不能直接作为稳定经验的证据。
- 数学经验应来自真实问题，而不是纸面练习。

### 5. 艺术领域

主要关注：

- 对自然、生活和艺术形式的感受。
- 使用声音、动作、色彩、材料和符号表达经验。
- 想象、替代、转换和创造。
- 形成个人审美偏好。

设计重点：

- 艺术评价首先关注意义表达。
- 不以作品像不像、整齐与否作为发展判断。
- 避免统一范例限制幼儿创造。

### 6. 游戏品质

游戏品质是园本跨领域观察维度，主要关注：

- 游戏意图和持续投入。
- 面对困难时的问题解决。
- 自主选择与资源使用。
- 想象、转换和创造。
- 合作与共同目标。
- 计划、回顾和经验迁移。

游戏品质不设置统一年龄达标线，必须结合幼儿兴趣、情境条件和教师支持进行理解。

## 八、证据判读规则

### 1. 事实、解释与假设必须分离

- **事实**：幼儿做了什么、说了什么、发生了什么变化。
- **解释**：行为可能体现什么经验、策略或兴趣。
- **假设**：需要通过后续观察继续验证的专业判断。

解释和假设不得被系统表述为已经确定的事实。

### 2. 一次行为不能形成稳定结论

形成较稳定的发展判断，应优先具备：

- 多个时间点的证据。
- 多个情境或材料中的证据。
- 多种证据形式。
- 教师审核。
- 支持后的后续观察。

### 3. 使用成长轨迹语言

系统使用以下描述：

- **初现**：在特定情境或较多支持下偶尔出现，需要继续观察。
- **发展中**：在相似情境中多次出现，策略或表现仍在变化。
- **较稳定**：在多个时间点较自主地出现，并能使用相关经验。
- **跨情境迁移**：能在不同场景、材料或关系中灵活使用经验。

这些描述用于表示证据稳定性和迁移情况，不表示幼儿等级。

### 4. 不能单独作为发展证据的内容

以下内容不能单独形成发展结论：

- 一次偶然成功或失败。
- 作品是否整齐、美观或与范例相似。
- 说话次数多或使用成人化词汇。
- 游戏时间长但没有明确行动意图。
- 被动服从成人安排。
- 从不寻求帮助。
- 完成成人预设步骤。
- 与其他幼儿比较后的相对位置。

## 九、教师支持策略设计依据

指标中心中的支持策略应遵循：

### 1. 最小必要介入

当幼儿正在持续思考和调整时，教师可以保持观察，避免过早提供答案。

### 2. 支持而不替代

教师可提供时间、空间、材料、问题、信息和同伴资源，但应把行动决定权逐步归还幼儿。

### 3. 支持必须指向后续观察

每项支持策略应同时说明：

- 为什么提供该支持。
- 依据了什么证据。
- 支持后重点观察什么。
- 如何判断该支持是否有效。

### 4. 支持类型

- 保持观察，暂不介入。
- 通过开放问题支持思考。
- 增加或调整材料。
- 调整游戏时间与空间。
- 支持同伴合作。
- 提供必要示范或信息。
- 支持记录、表达与回顾。
- 发起家庭协同观察。

## 十、AI使用边界

AI在指标中心中的角色是专业辅助，不是最终评价者。

AI可以：

- 推荐可能相关的指标。
- 整理客观观察事实。
- 提示需要继续验证的假设。
- 根据指标生成支持策略草稿。
- 检查是否缺少证据或存在过度推断。

AI不得：

- 自动判定幼儿达到或未达到指标。
- 根据单次观察形成确定性结论。
- 给幼儿生成综合分数或排名。
- 进行医学、心理或特殊教育诊断。
- 将没有发生的行为编造成证据。
- 未经教师审核向家长发布评价。

## 十一、指标治理与版本管理

### 1. 国家底座

- 保存原始来源、发布时间、版本和引用地址。
- 国家文件原文不可由园所修改。
- 专业转译内容必须与国家原文清晰区分。

### 2. 专业转译

- 由具有学前教育专业背景的人员编写。
- 由专家或教研团队审核。
- 保存转译依据、适用范围和非使用边界。
- 发现导致过度推断或教师负担过重时及时修订。

### 3. 园本扩展

园所新增指标时必须说明：

- 指标解决什么教育问题。
- 理论或实践依据是什么。
- 可观察行为和非证据是什么。
- 如何支持幼儿后续发展。
- 如何避免标签化和机械评价。

园本指标应经过草稿、专家审核、发布、停用的版本流程。

## 十二、系统设计结论

指标中心应被设计为：

- 教师观察的导航器。
- 专业判断的证据约束器。
- 教师支持策略的生成器。
- 幼儿成长轨迹的组织工具。
- 游戏课程生成的线索来源。
- 园所教研和持续改进的知识底座。

指标中心不应被设计为：

- 幼儿能力测验。
- 统一达标检查表。
- 幼儿或班级排名工具。
- 教师绩效考核分数来源。
- 自动诊断系统。

只有坚持真实情境、连续证据、教师审核、儿童权益和持续改进原则，指标中心才能真正帮助教师看见幼儿、理解游戏，并提供更适宜的教育支持。

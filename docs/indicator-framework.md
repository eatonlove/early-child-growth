# 指标中心专业框架

## 定位

指标中心是教师观察与支持决策的导航系统，不是幼儿达标量表。国家文件中的目标用于理解发展方向，系统中的“可观察行为”是理论转译后的观察提示，不等同于国家文件原文，也不能脱离情境用于直接测查。

## 三层结构

1. **国家与理论依据层**：国家发展指南、教育纲要、保教质量评估指南，以及形成性评价、真实性评价、社会文化学习、最近发展区等理论。
2. **专业转译层**：领域、子领域、发展目标、游戏中可观察行为、非证据、适宜支持、适用场景与证据类型。
3. **个体证据层**：真实观察、幼儿原话、作品和关键媒体片段；经教师审核后形成初现、发展中、较稳定、跨情境迁移的轨迹描述。

## 使用规则

- 一次观察可以关联多个指标，但应只关联有直接证据支持的内容。
- “可观察行为”用于提示教师看什么，不要求每次全部出现。
- “非证据”用于阻止常见误判，例如将偶然成功、作品整齐、说话次数或服从成人当作发展结论。
- 年龄段表现只用于理解一般发展方向，不用于给幼儿设统一时间表。
- 形成“较稳定”或“跨情境迁移”判断前，应有多个时间点、多个情境或多种证据支持。
- 所有解释和策略均应允许教师修改、拒绝，并通过后续观察验证。

## 指标治理

- 国家底座：锁定原始来源、版本与引用，不允许园所修改原文。
- 理论转译：由学前教育专家审核，记录转译说明、适用范围和版本。
- 园本扩展：必须说明专业依据、使用目的和非使用边界，经教研审核后发布。
- 每学期复核指标使用情况，删除导致标签化、过度推断或教师负担过重的指标。

## 国家依据与来源

- [《3-6岁儿童学习与发展指南》](https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/jyzt_2015nztzl/xueqianjiaoyu/yaowen/202104/t20210416_526630.html)：五大领域、三个年龄段的发展方向与教育建议。
- [《幼儿园保育教育质量评估指南》](https://www.moe.gov.cn/srcsite/A06/s3327/202202/t20220214_599198.html)：突出过程评估、强化自我评估、聚焦班级观察，并禁止通过直接测查幼儿能力评估保教质量。
- [《中华人民共和国学前教育法》](https://qspfw.moe.gov.cn/html/sublaws/20241111/22405.html)：坚持以游戏为基本活动，遵循学前儿童身心发展规律和年龄特点。

系统内的可观察行为、非证据和支持策略属于专业转译内容，不标注为国家文件原文。

# 2026-10-13客户反馈实施方案

## 本轮范围

1. 修复课程资料上传容量限制，单文件上限从30MB提高为500MB，统一页面、API、数据库、私有存储和代理限制。采用流式上传及进度提示，失败后保留成功文件和同一份草稿，不重复新建资源包。
2. 资源库按“懂生活、慧创生、悦生长”分类，分类下展示课程及其计划、材料、手册、补充资料。支持在线查阅与下载。已有资料仅根据明确的名称前缀回填分类，不明确的保留“待分类”，供教师或教研员调整。
3. 简化分类AI：用户主动点击后，依据该分类已入库资料输出“指向内容”和“指标侧重”，附课程来源链接及资料局限提示。不建设复杂的新指标体系，不自动触发AI，不以课程资料直接判断幼儿达标。
4. 将“内容摘要”改为“活动来源”，保留原摘要作为历史内容，支持未完成或退回草稿编辑。
5. 未完成、退回的资源包可以继续上传或删除；删除关联本草稿文件，已入库资料不得通过此入口删除。
6. 本轮不创建客户提出的教师账号。

## 分类AI输入与提示词

- 输入：分类名称、已入库课程编号与标题、活动来源、已解析课程正文和提取限制。
- 独立提示词键：`resource_category_analysis`；教研员提示词配置中可查看和修改，使用已有园所统一模型配置。
- 指向内容：概括材料中实际出现的生活经验、探究主题和活动方向，引用来源课程编号。
- 指标侧重：指出材料能够支持的经验或《指南》相关领域关注点，说明适合观察的具体行为，引用来源课程编号。
- 约束：不得虚构课程内容、国家指标编码、幼儿行为或学习成效；正文不足时明确说明，不用标题代替正文作确定结论。
- 输出不会自动写入国家知识库，不替代教师专业判断；资料变化提示重新分析。

## 验收与边界

- 本地真实接口验收500MB边界、超过500MB拒绝、Word正文阅读、资料提交、主动分类分析、删除保护及测试文件清理。
- 覆盖前后端契约检查、单元测试、生产模式构建和浏览器交互测试。
- 线上变更前备份同迹所属schema和被修改的代理/存储配置，保留其他应用与客户数据。
- DOCX提供文字阅读版，PDF和图片使用私有签名链接预览，下载保留原文件。
- 大于32MB的PDF及旧版DOC不进行无界内存解析；分类AI需可提取的文字正文。DOCX正文有节选预算，图片不自动OCR，分析中明确披露。
